# PowerBI-Chocolate-Sales-Analytics
This Power BI project provides a comprehensive analysis of sales data for a chocolate manufacturing/distribution business. The dashboard is designed to help stakeholders identify sales trends, monitor regional performance, and analyze product profitability to drive data-informed decision-making.

## Key Features
* **Sales Performance Tracking**: Visualizes total revenue, units sold, and profit margins.
* **Geographic Analysis**: Interactive maps and charts showing performance by city and region (utilizing custom City Park themes).
* **Time-Series Insights**: Analysis of sales trends over days, months, and years to identify seasonal peaks.
* **Product Deep-Dive**: Breakdown of performance by specific chocolate types or product categories.
* **Advanced Data Modeling**: A robust schema with established relationships between sales, products, and geography tables.

## Technologies Used
* **Power BI Desktop**: For data modeling, DAX calculations, and visualization.
* **DAX (Data Analysis Expressions)**: Used for custom measures (e.g., Year-over-Year growth, Profit %).
* **Power Query**: For data cleaning and transformation.
